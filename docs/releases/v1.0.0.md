# v1.0.0 — Lamplight

The first tagged release of the portfolio: a scroll-driven, candlelit record
built on eight public-domain paintings, where a moving light reveals both the
art and the metrics. Every date below is the commit date in this repository.

## How it got here

- **2026-07-30 — the evidence file.** The first site: a static export with
  build-time GitHub provenance on every project, JSON-LD, a styled 404, the
  résumé, and the first research benchmark chart.
- **2026-08-06 — the site verifies itself.** Case-study pages, `llms.txt`,
  richer JSON-LD and OG cards, a print stylesheet, and the CI quality gate:
  typecheck, lint, build, a JS budget, Playwright smoke tests and an axe scan.
- **2026-08-16 — Lamplight.** The redesign: eight acts, each set in a
  public-domain painting cropped and committed with a checksum lockfile, and
  one lamp — a single animation loop — revealing the plates and igniting the
  numbers its light reaches.
- **2026-08-20 — the light is the only moving thing.** Every zoom and
  push-in was removed after the owner saw them live; the paintings are still.
  The same week added SEO, social cards and the thirty-second recruiter path.
- **2026-09-05 — the night archive.** A synthesized candlelit soundscape
  behind an honest first-interaction gate, small interface sounds, and one
  light: the page-wide torch went, and the lamp gained a candle's falloff.
  The cursor became an original key and lock.
- **2026-09-07/08 — the CollectUI waves.** Interaction details translated
  from credited references: pressable brackets, a stamped confirmation, a
  carried nav highlight, odometer numbers, visible receipts, a gliding ledger
  marker, the soundscape's square switch, the act rail, the case-file index.
  The owner's carved-stone seal replaced the traced monogram.

## What this release adds (2026-09-18/19)

**The record tells the truth.**
- Warden's case file is re-sourced from the repo as it stands: 14 analyzers,
  13 / 14 malicious samples detected on its synthetic benchmark (named as a
  regression baseline everywhere), and 2,908 backend tests passed in CI.
  The exhibit no longer prints a command nobody ran.
- The scheduler study says only what its own honest-claims record allows:
  41,786 real plus 3,646 synthetic dispatch instants, the corrected model fit,
  and the required statistical caveats.
- PlantPal+'s stated gaps follow its README. Fillwright joins the archive.

**One canonical URL.** Both deploys now name the Vercel primary; the GitHub
Pages mirror stops presenting itself as the original. A weekly deploy hook
keeps the primary's record fresh.

**Security posture.**
- A Content-Security-Policy and four more response headers, each allowance
  explained in `scripts/csp.mjs` and proven by re-running the smoke, lamp and
  sound suites under the real headers. Verified live on Vercel.
- `/.well-known/security.txt`, tested so it can never expire silently.
- Dependabot for grouped monthly updates.

**The front door.** A README that shows the site and states its proof, an
MIT licence with the content carved out, complete package metadata, a
social preview, and the GitHub presentation strings.

**Hygiene and load.**
- The cursor was redrawn to read at 40px.
- The design captures went WebP, from 16.9 MB to 1.3 MB.
- The cursor source moved out of a root folder with spaces in its name.
- Dependencies were refreshed within their ranges.
- Chivo stopped preloading: mobile TBT fell from about 134 ms to about 53 ms
  across nine measured runs.
